# Свадебное приглашение

Готовый адаптивный шаблон в стиле примера https://amoura-invite.tilda.ws/love.
Все имена, даты, адрес и фотографии — демонстрационное наполнение из примера, а не данные вашей свадьбы. Дата перенесена на 26 июня 2027, чтобы показать работающий отсчёт.

## Запуск

Установлен только Node.js, дополнительные пакеты не нужны. В папке проекта выполните:

    

Приглашение: http://localhost:4173
Редактор: http://localhost:4173/editor.html

Остановка сервера: Ctrl+C. Для простого просмотра можно открыть dist/index.html напрямую, но экспорт из редактора требует запуска сервера.

## Как заменить содержимое

1. Откройте редактор. Поменяйте имена, дату, тексты, фото, адрес, программу и палитру. Фотографии загружаются с компьютера, автоматически уменьшаются до 1600 пикселей; оригиналы не меняются.
2. «Сохранить настройки» выгружает wedding-settings.json, включая загруженные фотографии. «Импорт» восстанавливает его. Для новой свадьбы используйте другой файл настроек.
3. «Скачать сайт» создаёт один invitation.html со встроенными фотографиями, стилями и скриптами. Его можно открыть без интернета или переименовать в index.html и разместить на любом статическом хостинге. Ссылки на карты и почта используют интернет.
4. Для обновления полной версии с редактором нажмите «Скачать content.js для публикации», замените dist/content.js и заново загрузите папку dist на хостинг.

Можно редактировать dist/content.js вручную. Всё содержимое вынесено в один объект window.WEDDING. Изображения по умолчанию лежат в dist/assets. Поля photos.*Alt — текстовые описания для доступности. Программа и пожелания поддерживают добавление, удаление и перестановку пунктов. Формат event.timezone: +03:00 для Москвы.

Редактор хранит черновик в localStorage вашего браузера. Он не меняет опубликованное приглашение автоматически. Браузеры и разные компьютеры не синхронизируют черновики. Сохраняйте настройки в JSON.

## Анкета гостя

По умолчанию анкета скачивает текстовый ответ. Ответ НЕ отправляется автоматически и нигде на сервере не сохраняется. Это явно указано гостю.

Укажите rsvp.email в редакторе: после заполнения откроется почтовое приложение с подготовленным письмом. Гость должен самостоятельно нажать «Отправить». Для этого у гостя должна быть настроена почта.

Для централизованного сбора ответов укажите rsvp.formUrl: встроенная форма заменится кнопкой перехода на вашу внешнюю анкету, например Яндекс Формы или Google Forms. Создание анкеты и настройка сбора ответов выполняются в выбранном сервисе.

## Публикация и повторное использование

Для статического хостинга загрузите содержимое dist. Для однофайловой версии загрузите экспортированный invitation.html как index.html. Сохранение настроек в редакторе не публикует изменения. Редактор не содержит секретов и не является закрытой админкой: посетители могут сделать собственную локальную копию, но не могут изменить файлы вашего сайта. Удалите editor.html, editor.js и editor.css из публичной копии, если редактор гостям не нужен.

Перед рассылкой замените демонстрационные данные и фотографии, проверьте адрес, дату, часовой пояс и способ получения ответов. Демонстрационные изображения загружены из указанного вами примера и могут требовать замены на ваши фотографии для публичного использования.

Проект без зависимостей и этапа сборки. Основные файлы: dist/index.html, dist/styles.css, dist/app.js, dist/content.js; редактор: dist/editor.html, dist/editor.css, dist/editor.js. Локальный сервер раздаёт только dist и не открывает доступ к исходникам и метаданным Git.
