# Подключение вашей Google Таблицы

Код уже настроен на таблицу:
https://docs.google.com/spreadsheets/d/1uxy1JH6sGbZElNxZWQIkQ3oNfnX-FaTJ3be3LQrnvJY/edit

Он создаст отдельный лист «Ответы гостей». Существующие листы не изменяются.
До заполнения адреса скрипта приём ответов на сайте отключён: гости видят пояснение.

## Один раз в аккаунте владельца таблицы

1. Откройте таблицу → **Расширения → Apps Script**.
2. Замените содержимое `Код.gs` / `Code.gs` всем кодом из [Code.gs](Code.gs), сохраните.
3. Выберите функцию **setup** в верхнем списке и нажмите **Выполнить**. Разрешите скрипту доступ к Google Таблицам под аккаунтом владельца. Убедитесь, что в таблице появился лист «Ответы гостей». Функцию `doPost` вручную запускать не нужно.
4. Нажмите **Развернуть → Новое развертывание → Веб-приложение**.
5. **Выполнять от имени:** «Я»; **У кого есть доступ:** «Все» / `Anyone`, включая пользователей без Google-аккаунта. Если анонимный доступ запрещён администратором Google Workspace, используйте аккаунт, где такое развёртывание разрешено.
6. Нажмите **Развернуть** и скопируйте **URL веб-приложения**, заканчивающийся на `/exec`. Адрес таблицы и ссылка на редактор Apps Script для отправки не подходят.
7. Откройте редактор приглашения → **Анкета**. Оставьте способ «Google Таблица», вставьте URL в поле **Адрес Google Apps Script для сохранения ответов**. Поле **Ссылка на внешнюю анкету** должно оставаться пустым.
8. Нажмите **Скачать content.js для публикации**, замените `dist/content.js` и обновите сайт. Или экспортируйте однофайловое приглашение заново. Можно передать URL `/exec` Codex для внесения в проект.
9. Отправьте тестовый ответ с обычной страницы приглашения, не из предпросмотра редактора. Проверьте новую строку и сообщение «Ваш ответ сохранён». Повторная отправка неизменённого ответа с этой страницы не должна создавать вторую строку.

Не требуется включать Google Sheets API, устанавливать пакеты, размещать отдельный сервер или добавлять пароли в сайт.
`appsscript.json` приложен для импорта проекта; при ручной вставке `Code.gs` разрешения определяются Google автоматически.

## Доступ к данным

Для работы скрипта достаточно прав его владельца. Верните общий доступ к самой таблице в состояние **Ограниченный доступ**, а организаторов при необходимости пригласите персонально. Гостям не нужны права чтения или редактирования таблицы.

Веб-обработчик принимает публичные анкеты и не возвращает их содержимое. Это не авторизация гостей: отправить новый ответ может любой, кто получил адрес обработчика. Поле-ловушка и проверка длины не заменяют защиту от массового спама; для открытого массового сайта потребуется отдельное ограничение частоты или CAPTCHA. Для списка приглашённых не публикуйте ссылку широко.

## Как это работает

Браузер отправляет POST через скрытый iframe. Apps Script проверяет поля, блокирует параллельную запись, проверяет ID ответа, записывает строку и выполняет `SpreadsheetApp.flush()`. Затем он возвращает подтверждение через `postMessage`. Сайт проверяет домен Google, принадлежность окна iframe и случайные идентификаторы. Загрузка iframe сама по себе не считается успешной записью; `no-cors` не используется.

Имя и спутник — до 140 символов, пожелания — до 1500. Время получения задаёт сервер в часовом поясе Москвы. Текст, похожий на формулу, экранируется.
При ошибке или отсутствии подтверждения за 45 секунд поля остаются заполненными. Повторная попытка без изменения полей использует тот же ID. ID хранится в памяти открытой страницы: после перезагрузки или изменения ответа новая отправка считается новой анкетой.
Для работы отправки нужен интернет, в том числе при открытии экспортированного HTML с компьютера.

## Если запись не работает

- Проверьте ссылку `/exec`, права «Все» и выполнение от имени владельца. Проверьте сайт в приватном окне без входа в Google.
- Откройте раздел **Выполнения** в Apps Script и проверьте ошибки, доступ владельца и квоты.
- После изменения скрипта: **Развернуть → Управление развертываниями → Изменить → Новая версия → Развернуть**. Простого сохранения кода недостаточно.
- Не меняйте заголовки первых семи столбцов листа «Ответы гостей». Дополнительные столбцы можно добавлять справа.
- В предпросмотре редактора отправка намеренно отключена. Старый браузерный черновик может содержать другой способ получения ответов — проверьте вкладку «Анкета».

Проверка локального кода: `node --test tests/rsvp.test.mjs` из папки `invitation`.
Локальные тесты не заменяют проверку реального развёрнутого скрипта и строки в таблице.
